# Phase 5 考试与作业

沿用 Exercise、Question、Submission、QuestionAnswer 和现有教师批改页。单选、多选、判断题的自动评分和简答题人工批改已有实现，作业继续使用普通练习。

本阶段先增加考试模式与服务端时间窗：考试开放前及结束后学员不能读取题目或提交，开放期间读取的题目不包含答案键。管理员仍可编辑和批改。公开课程使用本地练习评分，不能启用考试模式。考试时间采用带时区的时间戳，旧练习默认不是考试，保持已有数据行为。

后续在同一阶段实现持久化开考时间、时长、次数与补考规则，再补共享题库的题目复制/版本机制；这些规则未落地前不在界面上声称可限制考试时长或次数。
