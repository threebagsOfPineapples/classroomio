# 页面与导航结构

现有 dashboard 是 SvelteKit 单应用，`(app)` 路由提供组织管理和 `/lms` 学习页，`(org-site)` 提供公开课程站。新 `/admin`、`/learn` 应在同一 app 中作受保护入口，复用课程、Cohort、成员、题目、证书和图表组件。旧 `/org/[slug]`、`/lms`、公开课程详情链接继续可用；不要第一阶段重写所有路由或翻译系统。当前页面证据见 `apps/dashboard/src/routes/(app)/org/[slug]/`、`(app)/lms/`、`(app)/courses/` 与 `apps/dashboard/src/lib/features/lms/`。

| 入口 | 一级导航 | 初版页面/复用点 |
| --- | --- | --- |
| `/admin` | 工作台 | 今日培训、待评分、即将到期、未完成人数；沿用组织 Dashboard、analytics 图表。无来源数据用“待配置/暂无数据”，不填 0。 |
| `/admin/training` | 培训计划、班级/项目、任务、人员、记录 | 计划新建/发布、目标预览、固定 Enrollment；班级页复用 Cohort 课程/成员/目标。 |
| `/admin/courses` | 课程、分类、课时、讲师、评价 | 课程/章节/课时沿用现有编辑页；分类首选 tag；满意度新页。 |
| `/admin/assessment` | 题目/练习、考试、批改、综合成绩 | 沿用练习编辑、提交与成绩册；新增加权方案、明细、调分记录。 |
| `/admin/employees` | 员工、部门、档案、证书 | 组织 audience 作为员工列表基础；部门树、成员企业属性、计划培训档案新视图。 |
| `/admin/analytics` | 培训/部门/员工/成绩/满意度 | 复用现有图表容器与分析组件；每个数字附时间口径和分母。 |
| `/admin/settings` | 企业角色/权限 | 组织成员管理基础上增加企业授权；平台账号配置继续走旧设置页。 |
| `/learn` | 首页 | 姓名、部门、岗位、待办、继续学习、近期培训、考试和证书；复用 `/lms` 学习卡片，不按后台表格设计。 |
| `/learn/training` | 我的培训 | 固定任务和计划详情，按截止/状态筛选。 |
| `/learn/courses` | 学习中心、课程中心 | 继续学习与内部可见课程，复用 `/lms/mylearning`、`/lms/explore`、课时播放；不展示支付。 |
| `/learn/exams` | 考试中心 | 待考、进行中、已交、补考；沿用 Exercise 提交体验。 |
| `/learn/results` | 我的成绩 | 计划分数、逐项来源、待评分与调分记录（只读）。 |
| `/learn/archive` | 培训档案 | 历史培训、学时、证书、通过率；本人范围。 |

## 渐进交付与体验规则

Phase 1 仅交付部门/员工/授权管理界面和入口权限框架；Phase 2 接课程；Phase 3 接计划/任务；Phase 4 完成员工学习主页；后续按实施计划逐项加入口。导航项只在页面及 API 真正可用时出现，避免空白模块。管理端信息密度适中、支持过滤/批量分配与明确状态；学习端以课程内容和下一步行动为主，保持键盘可达、文本对比度和移动屏幕可用。中文新文案按现有 i18n 规则维护多语言文件；不把“当前缺数”伪装成业务零值。

## 验收路径

管理员创建 Q4 计划 → 选直播运营部门并预览名单 → 关联四课程和 40/30/20/10 方案 → 发布 → 张三在 `/learn/training` 见任务并学习/考试/提交作业 → 讲师评分 → 管理端核对 89.9/PASS → 张三评价培训 → 档案和部门 Dashboard 同步显示。这是跨阶段的最终业务验收，Phase 0 仅定义流程，不声明已可运行。
