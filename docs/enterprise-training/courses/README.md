# 企业通用入门课程包

适用对象：新入职员工、直播运营助理、需要参与复盘的业务人员。三门课程均为原创整理的内部培训草稿，不代表职业资格认证，也不替代公司的正式制度。

每门课程包含四个课时、场景练习和五道单选测验。案例事实与教学推演分开标注；测验只检查本课学习内容，不自动签发证书。建议先由人事、运营负责人审核，再分配给学员。

| 课程 | 建议学习时间 | 学习产出 |
| --- | --- | --- |
| 新员工入职与工作协作 | 45 分钟 | 入职核对表、任务交接单、信息安全处置记录 |
| 直播运营基础与开播执行 | 60 分钟 | 商品证据卡、开播检查表、异常处理记录 |
| 直播数据复盘与改进 | 60 分钟 | 指标口径表、复盘结论、下一场验证计划 |

## 公开案例来源

- [市场监管总局：直播电商领域典型案例，2025-04-18](https://www.samr.gov.cn/xw/zj/art/2025/art_aa3fc21f7586462593b51175ba385186.html)：使用杭州杰福的口播证明材料问题和北京萱妍堂的虚假互动案例，各以简短摘要引入；操作清单与练习为本课程原创。
- [最高检：侵犯公民个人信息犯罪典型案例，网信办转载，2017-05-16](https://www.cac.gov.cn/2017-05/16/c_1120983088.htm)：使用员工接触客户资料后的违规流转风险，案件用于历史警示，不将当时处罚规则作为现行法条教学。
- [人社部：国家基本职业培训包通知，2023-07-14](https://www.mohrss.gov.cn/xxgk2020/fdzdgknr/qt/fzcwjxx/202307/t20230714_502943.html)：课程组织参考培养目标、培训内容、考核与资源相配套的思路；本课程不是官方培训包。

检索日期：2026-09-28。原文仅作为阅读链接，未复制整篇材料或付费课程。

## 发布前需补齐

由公司填写：入职联系人、岗位说明、考勤和请假入口、设备领用流程、数据导出审批路径、异常上报联系人。未确认的信息保持“待公司补充”，不能让学员据此执行未批准的规定。

复盘课中的两场直播数据均为教学模拟，已在课时内明示；不得作为公司业绩或平台行业基准。

## 本地导入

课程正文与题目位于 `course-library.json`。在仓库根目录运行 `node scripts/import-training-courses.mjs` 可检查课程包；添加 `--apply` 才写入本地系统。执行写入前设置 `TRAINING_ADMIN_EMAIL`、`TRAINING_ADMIN_PASSWORD`、`TRAINING_ORG_ID`。脚本仅连接本机 API，使用现有权限校验，并将新课程保持为草稿。

导入进度保存在系统临时目录中的 `enterprise-training-course-import.json`，可安全重跑已记录的导入；已存在同名课程但没有导入记录时停止，避免覆盖已有内容。脚本不会发布、分配课程或修改证书与权限。

发布审核使用 [课程发布审核单与讲师答案](publication-review.md)。其中的答案只供管理员和讲师使用，不作为学员测验附件。
