# 系统判定学习完成与顶部语言入口

日期：2026-09-28。

## 行为

- 课程侧栏移除 ClassroomIO 技术支持链接。
- 普通课时取消桌面、手机手动标记完成入口，服务端旧接口拒绝手动修改。
- 图文正文与 PDF 采用系统阅读判定：正文按每秒 5 字估算，每份 PDF 增加 60 秒，课时最低 60 秒；还须到达正文末尾、浏览每份 PDF 的所有页面。
- 每 5 秒同步，时长由数据库时钟计算；后台、失焦、60 秒无交互时暂停，超过 15 秒的请求间隔不补计。首次请求和恢复后的首次请求不计时，重复请求不重复累计。
- 配置为 video_watch 的课时继续使用原视频观看规则。包含无法核验的外部视频、嵌入幻灯片或非 PDF 附件时明确提示管理员处理，不自动放行。
- 课程学习完成、测验通过、证书签发继续独立判定。既有已完成记录不回滚；本次规则作用于新的阅读记录。
- 系统语言入口集中在管理端、学员端、课程、培训班顶部。默认简体中文，主动选择其他语言后使用浏览器存储和 cookie 记住选择。课程正文仍优先使用中文；旧的课时语言入口及个人设置入口不再展示。

## 数据库

新增迁移 `0028_lesson-reading-progress.sql`，只为 `lesson_completion` 增加阅读秒数、最近心跳、活动状态和读完资源四列，不删除或重算历史成绩。

本地执行常规迁移时发现 0027 对应表已经存在，但历史 ledger 时间早于当前 journal。核对已有表与字段后，在事务中单独应用 0028 并写入其迁移记录，没有重跑 0027 的业务数据修改。其他环境应按各自 ledger 核对后运行正常迁移。

## 边界

浏览器阅读信号能作为系统学习记录，不能证明注意力或掌握程度，也不能完全防止具备技术能力的人伪造客户端信号。因此考核成绩仍需独立测验。

可见性与焦点分别参考 [MDN Page Visibility API](https://developer.mozilla.org/en-US/docs/Web/API/Page_Visibility_API) 和 [Document.hasFocus](https://developer.mozilla.org/en-US/docs/Web/API/Document/hasFocus)。

- API 与 Dashboard 生产构建通过；最后一轮 Dashboard 134 项测试通过。
- 浏览器验证顶部只有一个语言入口，切换英文并刷新仍保留选择，可切回中文；课程侧栏技术支持链接为零。
- PDF 页浏览事件已接入内置阅读器，尚未使用真实上传的 PDF 完整跑通端到端验收。

## PDF 阅读修复（2026-09-29）

- 前后端共用 PDF 文件识别，支持 `pdf`、`application/pdf` 及 `.pdf` 文件名；修复 MIME 类型 PDF 被外部打开而无法记录阅读的问题。
- 每页渲染成功且页末进入阅读容器可见范围后才计为已读，全部页面满足且当前为最后一页时报告读到末尾。后台、失焦和未显示完的页面不计。
- 快速翻页、缩放、关闭或切换文件使旧异步结果失效，避免将旧页面误记到新页或其他文件。阅读器脚本加载最多等待 10 秒，失败显示现有错误提示。
- 翻页、缩放、关闭共五条提示改为翻译键，已补齐 11 种界面语言。

验证：11 项文件识别与页末可见范围测试通过；共享 utils 和 API 编译通过；阅读器组件客户端、服务端编译均零警告；翻译同步及新增键、占位符检查通过。本轮未做 Dashboard 完整构建或浏览器真实上传验收，也未重启运行服务，不能据此认定 PDF 端到端验收完成。非 PDF 附件、外链视频及幻灯片的自动完成覆盖仍待处理。

## 发布前完成判定检查（2026-09-29）

- 课程由未发布切换为发布时检查课时；培训计划发布和追加员工时重新检查关联课程，避免将不可完成的课时继续分配。
- 阅读判定要求存在正文或有效 PDF，不能混入未支持的外链视频、幻灯片或非 PDF 附件。缺少文件标识的 PDF 也不通过。
- 视频判定复用原视频追踪规则，必须存在可追踪的上传视频；不改变观看比例、视频选择、评分或证书逻辑。

- 阅读要求提取至 utils，由学习心跳和发布检查共用；查询层支持传入现有发布事务，没有新增迁移。
