## 旧入口及后端边界

- 公开课程主页、公开课件、组织展示页和组件页面返回内部课程库；原邀请 token 页面保留。
- 组织宣传页、组件管理、自动化与计费旧页面返回课程管理。
- `/course/slug/*`、`/org-site/course/*`（含课件、Markdown、HLS 授权）、`/widgets/*`、公开课程/标签目录、付费报名及课程宣传内容更新接口统一返回 HTTP 410。
- 原匿名 slug 查询可能读出未发布但 ACTIVE 的课程；本轮关闭整个入口。
- 无邀请 token 的自主选课必须已经属于课程所在公司，同时满足课程已发布、有效且允许自主选课。链接不创建新的组织成员。
- 既有课程邀请分支保留。企业自托管注册要求已有员工记录或有效邀请，首次组织初始化保留。
- 历史价格和缺失付款链接不再阻断内部课程更新；显式传入的非 HTTP(S) 支付 URL 仍被校验拒绝。
- 新课不再写入系统自动生成的英文欢迎公告。

关闭接口不会自动撤回此前已发出的对象存储链接；本轮也未批量迁移历史课程类型。
