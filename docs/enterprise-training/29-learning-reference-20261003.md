## 本地页面与代码对照

本地千川课程的首课时仍是短正文及外部官方课程入口。当前页没有视频，也没有挂接 PDF 或其他文件。这无法让员工在本系统完成所指向的官方课程，更不能取得员工在外站观看的实际时长。

本次本地浏览器页面使用管理员身份，不能用该管理视图证明员工实际学习已经计时。员工视图和管理预览的记录规则需要在真实报名账号下分别验证。

代码中已有正文/PDF 阅读心跳及上传视频观看进度能力；因此不能仅根据界面现象断言整个系统完全没有计时功能：

- `reading-progress.svelte` 与 `recordLessonReading` 提供活动阅读心跳和数据库时钟累计。
- `lesson-video-player.svelte` 与课时观看服务提供观看记录和续播位置。
- 当前视频记录以可跟踪的资源和完成策略为前提。外部网页链接不会自动变成可跟踪视频。
- 之前验证记录对真实视频、PDF 上传及完整学习完成链路仍有未覆盖项。这次参考检查不补足这些缺口。

## 修正后的验收标准

以下是根据用户需求及此次实际观察提出的本地验收要求，需通过实现与员工实测证明。

| 部分 | 验收要求 |
| --- | --- |
| 内容 | 真实、中文、适合国内企业的课程内容；公司介绍取自用户提供的公司网站。导学链接、岗位练习与正式课程内容明确标识。 |
| 学习入口 | 点击开始学习或继续学习，直接进入对应课时和实际内容；继续学习恢复保存的位置。 |
| 内容形式 | 中文视频、图文、文档按课程实际需要组织；PPT 可以作为讲师课件或配套资料。 |
| 计时 | 展示实际累计学习时长和保存状态；标称课时长与实际学习时长分别展示。暂停、后台、失焦、断网和多窗口按明确规则处理。 |
| 进度 | 根据有效观看或阅读记录判定完成，刷新后保留；课程及培训进度与课时记录一致。 |
| 管理端 | 能按员工、课程、课时查看实际时长、完成状态、开始及完成时间，并核对汇总来源。 |
| 发布 | 缺少真实内容或不支持跟踪的课程显示缺项，不能以资料链接可访问作为完整学习验收。 |
| 端到端 | 使用独立测试库的实际员工账号验证播放/阅读、暂停、退出、再次进入、达到完成条件及后台对应记录。 |
