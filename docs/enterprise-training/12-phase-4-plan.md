# Phase 4 员工学习中心

基线为 Phase 3 提交 `12a53a5fc`。沿用 ClassroomIO 的“我的课程”、学习内容、完成记录与继续学习路由；新入口 `/lms/training` 展示培训计划发布时生成的员工任务及其中的课程。

- `GET /enterprise/my-training` 仅按当前账号在当前企业的有效员工身份读取任务，按计划返回课程；不会实时重算部门或岗位名单。
- 页面用已有课程完成数据聚合培训进度；课程数据缺失或尚无可追踪内容时显示“暂不可用”，不把未知值当成零，也不写入任务进度缓存。
- 展开计划可查看课程、截止日期和继续学习入口。“我的课程”继续使用现有 LMS 页面。
- LMS、课程内容和公开课程布局使用同一返回顶部控件，长页面滚动一屏后才显示。

验证：API 任务分组、课程进度和返回顶部阈值的针对性测试；API、dashboard 构建；新增 UI 组件的 Storybook 展示与 Tailwind 前缀检查。无数据库迁移。
