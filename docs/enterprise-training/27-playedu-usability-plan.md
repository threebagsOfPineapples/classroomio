# PlayEdu 对照检查与本轮修改计划

日期：2026-10-02。核对基线：`65bcad1b6`。

## 核对结论

本轮实际查看本机管理和学习页面，并登录 PlayEdu 开源演示的管理端和员工端；另核对官方手册及源码。当前内部培训导航、品牌和员工首页已有统一基础，深层表单的误操作保护、培训准备步骤和考试状态仍需改善。

| 对照点 | PlayEdu 实际观察 | 本轮采用方式 |
| --- | --- | --- |
| 课程配置 | 建课抽屉连续配置基本信息、部门范围和课时，可选项折叠 | 保留现有培训与考核模型，用状态和下一步入口连接已有页面 |
| 管理列表 | 课程行可看指派范围、必修/选修，直接打开学员进度 | 明确课程计数和状态，补直接学员入口 |
| 员工学习 | 必修/选修完成数、待完成筛选、课时继续学习位置清楚 | 保留现有首页，补培训和考核直接动作、时间和失败重试 |
| 表单保护 | 建课抽屉点击遮罩不关闭 | 保留现有弹窗规范，补页内切换和发布前的未保存检查 |

参考：[官方仓库](https://github.com/PlayEdu/PlayEdu)、[快速上手](https://faq.playeduos.com/opensource-handbook/article/wFymJ4SXcX)、[管理演示](https://admin.playedu.xyz/course)、[员工演示](https://demo.playedu.xyz/)。演示为共享重置环境，人数与进度只代表查看时点。考试、学习任务等企业版功能没有冒充本次开源演示的实测结果。

## 修改清单

| 优先级 | 已核对问题 | 修改与验收要求 |
| --- | --- | --- |
| P1 | 评分草稿只按项目保存，切换员工后可沿用旧分数和调整值 | 清理或隔离人员草稿，切换与提交始终对应当前员工 |
| P1 | 考核表单改动未保存也能发布数据库旧方案 | 发布前检查未保存状态，确认用户发布的是当前已保存内容 |
| P1 | PDF 方向键同时触发课时导航；Esc 关闭会移除阅读监听且重开不恢复 | PDF 键盘事件只影响阅读器，关闭重开仍可记录页末阅读 |
| P2 | 计划新建/切换直接丢失未保存输入 | 页内切换、离开页面和发布均保护草稿 |
| P2 | 培训准备需要记住跨页保存和发布顺序，管理列表信息不足 | 增加步骤状态、直接下一步入口、计划周期及对象查找信息 |
| P2 | 员工页缺少直达单人邀请入口 | 复用现有邀请流程，不扩大人员批量导入范围 |
| P2 | 我的考核仅按提交状态分成四列，缺开放/截止和可参加状态 | 复用既有考试状态和权限，提供适合窄屏的任务列表 |
| P2 | 培训待办进入结果详情后缺学习或考试入口 | 从真实培训课程、考核数据提供下一步动作 |
| P2 | 证书、课程库、考核及培训页面失败与空状态混淆 | 单独展示失败原因与重试，不把失败当作无数据 |
| P2 | 课程库排序只作用于当前页 12 条 | 排序下沉查询层，在分页前排序，切换条件回到第一页 |
| P2 | 课程设置有公开 Markdown 和营销文案残留，资源空态与筛选措辞错误 | 清理无效入口，统一内部培训用语，提供资源准备的有效路径 |

## 实施边界

- 保持橙色品牌、中文默认及内部培训定位。
- 保留权限范围、学习完成、考核评分、培训结业和证书规则。
- 钉钉与人员批量导入继续后置。
- 复用现有组件、查询和服务；不增加框架、数据库模型或新依赖。
- 本轮交付本机可验证版本，不把构建通过当作用户业务验收完成。

## 验证安排

1. 对评分草稿、发布检查、考试状态、排序及错误恢复运行针对性检查。
2. 用浏览器验证计划草稿保护和 PDF 翻页/重开；需要数据的场景使用明确标注的浏览器响应夹具，避免改动用户课程。
3. 运行 Node 20 下的 API、Dashboard 及依赖构建，检查翻译占位符和改动文件格式。
4. 启动新版到现有本机地址，检查管理员/员工主要页面的桌面和手机布局。
5. 提供用户验证入口和操作清单，等待用户验证。

### 用户验证清单

1. 在培训计划中修改基本信息、课程和对象，检查步骤状态、保存/放弃及切换确认；按提示配置考核、核对人员后发布。
2. 修改考核方案但不保存，确认无法发布；保存后发布，核对发布内容。给员工甲输入评分和调整说明后切换员工乙，确认不会沿用甲的输入。
3. 从员工端的“我的培训”“我的考核”进入课程或考试，核对开放时间、待评分、已截止及不能参加时的提示。
4. 打开 PDF，使用方向键翻页，Esc 关闭后重新打开并读到页末；确认没有跳到下一课时。
5. 查看课程列表的课时/练习/员工数和学员进度入口，以及课件资源空态的上传路径；检查单人邀请的邮箱校验与结果提示。
