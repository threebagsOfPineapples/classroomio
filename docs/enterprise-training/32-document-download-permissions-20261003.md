# 课程文件下载权限验收

## 管理员入口

课程设置 → 访问权限 → 允许员工下载课件。按课程统一控制全部附件，使用已有 `course.metadata.lessonDownload`，缺省关闭。修改后通过底部保存栏保存。

- 开启：员工显示下载按钮，可保存 PDF、PPT 等附件。
- 关闭：员工隐藏下载按钮，PDF 在线阅读、翻页不受影响。
- 管理员和课程讲师可下载备课文件。
- 未加入课程、课时不属于课程、附件不属于课时、跨组织资产、锁定内容均不能取得正式下载许可。
- 非 PDF 附件不再通过“查看”直接打开原始文件，避免该入口触发文件下载。

## 实现

正式接口：`POST /course/:courseId/lesson/:lessonId/document/download`。

请求只提供持久附件的 `documentId`，地址和文件名由服务端从课时及同组织资产解析。学习页先请求正式许可，再获取文件。服务端优先返回原文件名，保留 `.pdf`、`.pptx` 扩展名。

旧 `document/download`、`video/download` 预签名接口对匹配到课程附件的原 key 和资产 storageKey 应用相同权限检查。同一文件被多门课程引用时，须至少存在一个本人有权访问并允许下载的课时。整课内容导出也使用课程下载开关。非课程素材、作业文件仍沿用原规则，未改上传流程。

复用现有元数据，无数据库迁移。全部 11 个语言文件已同步，中文界面使用中文错误提示。
