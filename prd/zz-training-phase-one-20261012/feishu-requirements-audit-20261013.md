## 4. 接入和验收不能漏掉的事项

1. **真实移动接入**：H5 布局可用不等于钉钉内身份、扫码与回跳已验证。使用真实手机验证问卷和签到入口、会话恢复、任务资格及退出；先核对已有应用和授权，按需调用，避免反复同步全量通讯录。
2. **现有人事系统嵌入**：确认实际宿主、进入/返回、身份共享方式、iframe/cookie 策略。仅加入 iframe 白名单不能作为身份互通验收。HR、薪酬、绩效计算仍不在一期。
3. **开放接口**：项目已有版本化公开 API 框架。需列清本期业务对外开放范围、鉴权、数据范围、字段版本及回流验收；内部页面能调用接口不能自动证明外部集成已交付。
4. **性能与兼容**：“日常学习不卡顿、看板秒级打开”需要先约定使用场景和响应指标，再在 119 记录学习、交卷和导出时的结果；历史总部人数不等于同时在线人数。兼容 iOS/Android 与主流浏览器，并测试重启、备份和恢复。
5. **一个培训岗可操作**：让培训岗独立完成空库建课、派课、出卷、问卷、签到、绑定导师、批量督学和导出。标准业务不依赖技术人员改 SQL；技术运维责任单独明确。
6. **原文排期**：里程碑表的一期 6–8 周是提需时建议，不能直接当作目前剩余工期。根据剩余实现、真实接口联调和验收资源重新排期。
