# 一期功能实现与验证记录

日期：2026-10-13。分支：`codex/phase-one-functional-completion`，基于 Gitee `5f3ba17a`。本轮为问卷、线下签到、导师带教及共用权限的功能实现，不代表全部一期需求已经上线。

## 已确认的业务规则

- 使用 PC 管理端与手机版 H5，沿用现有钉钉账号接入；域名 `train.hnzz.top`、`m.train.hnzz.top` 的启用继续暂缓。
- 一期培训范围是主公司 `967223303` 子树，排除长沙 `1076307045` 子树。接口样本 933 位员工中，实际保留 593 位；组织树保留 162 个范围内节点和 2 个结构祖先，组织节点数不等同提需中的一级部门数。
- 样本范围内 7 位员工属于多个部门。这是正常任职关系：主部门可空，不阻断导入，不猜测新员工的主部门；同步所有范围内部门关系。名单、任务与人数按员工 ID 去重。
- 运营部五位主管按明确授权的小组或人员看数据。选中父部门不会自动包含后代；未授予管理范围时只有本人数据。身份与权限不从岗位名称推断。
- 导师点评后是否需要主管复核由任务配置；复核人必须具有该学员的有效管理范围。点评、复核、认证各自留痕。

## 本轮实现

| 模块 | 真实页面与接口能力 | 边界 |
| --- | --- | --- |
| 问卷 | 模板编辑、发布后固定内容；独立调研和课后课程评价；定向名单；二维码/链接；H5 草稿和一次正式提交；回收及答案 CSV | 二维码不能替代登录和参与资格；匿名答卷与人员参与记录分开，关闭后仅整体统计，暂不展示匿名自由文本 |
| 线下签到 | 场次草稿、固定应到名单、发布/关闭、限时二维码刷新/撤销；H5 本人签到；补签、请假、撤销及原因审计；缺勤统计与 CSV | 不允许客户端指定代签员工；二维码仅存摘要；真实钉钉手机扫码仍需现场验证 |
| 导师带教 | 批量师徒绑定、导师交接、课程/考试/实操任务、学员提交、导师点评打分、可选主管复核、独立认证和全历史 CSV | 实操作业本轮支持说明与完成确认、导师现场核验；尚未新增作业附件上传、双向评价、定时自动催学 |
| 权限 | 新增 MENTOR、EXECUTIVE 角色；超级管理员配置主管精确部门/人员范围；新培训模块隔离 HR 管理能力、员工本人和主管范围；停用/离职/越权拦截 | EXECUTIVE 仅建立角色与汇总权限语义，本轮没有完成老板专用大盘；不自动给任何真实人员授予角色 |
| 钉钉目录 | 预览与同步均执行总部过滤；保留树祖先用于展示；全量有效多部门关联；事务内绑定预览与选择 | 现有同步仍是管理员预览后执行，尚非钉钉入职事件自动同步/自动派课 |

页面入口：`/admin/surveys`、`/admin/sessions`、`/admin/mentorships`；学员入口分别为 `/lms/surveys`、`/lms/sessions`、`/lms/mentorships`。权限编辑器位于员工管理的角色区域，仅超级管理员显示。

带教考试任务需要固定的分值和及格线依据。缺少不可变考试快照的旧答卷不能套用现在的试卷分值直接认证；调整试卷后需要重新下发任务。课程进度、考试结果、导师评分和最终认证分别呈现。

## 数据变更和验证环境

本分支只有一个新增迁移 `0030_phase-one-training.sql`，包含问卷、签到、带教、显式授权、操作审计和多部门关联。已有主部门回填为一条部门关系：钉钉来源标为 DINGTALK，其他标为 MANUAL；后续同步替换本次所选员工的钉钉关系，保留人工关系与未选员工历史。

所有本轮数据库验证使用专用本地 PostgreSQL 容器及虚构账号，未连接业务数据库，也未导入真实员工原始文件。原始钉钉预览 token 与个人明细不进入仓库。数据库集成测试必须显式设置 `TRAINING_TEST_DATABASE_URL`，且只接受回环地址、数据库名 `training_phase_one`。

自动验证共 215 项通过：API 侧 205 项（其中 6 项真实 PostgreSQL 集成测试）、总部范围纯函数 4 项、授权页面状态 6 项。真实数据库覆盖跨组织外键、空范围拒绝、无主部门多部门去重、并发匿名答卷、并发扫码、可选主管复核与独立认证，以及离职账号对原人工考勤接口的拦截。

另在独立升级测试库通过 51 项检查：先应用至 0029 并写入旧结构样本，再升级 0030；核对 MANUAL/DINGTALK 回填、重复迁移无重复、约束和快照一致性。新评审/认证表中的人员 ID 单列外键只保证人员存在，同组织授权由服务层校验，不能把外键检查误当完整权限验收。

API 和 Dashboard 完整构建通过；九种其他语言各补齐 320 个新增词条，`pnpm translate` 最终检查无缺失，占位符保持一致。浏览器检查发现并修复了新表单重复标识，以及带教页面共用组件插槽使用不匹配的问题。构建和本地浏览器检查不等于正式部署或钉钉手机业务验收。

浏览器使用虚构账号检查了问卷草稿保存、签到名单、390 像素宽 H5 带教任务与点评/复核/认证历史，以及主管授权对话框读取。测试环境仍有既有遥测脚本 CSP 拦截和 `/ingest` 404；这些没有作为业务接口通过的依据。多测试组织切换期间的无成员请求被 403 拒绝，选定正确组织后的业务请求正常。

本机 Dashboard 构建需要 `PUBLIC_IS_SELFHOSTED=true`；本次完整打包使用 `NODE_OPTIONS=--max-old-space-size=8192`，默认堆大小曾出现内存不足。没有因此改动业务代码。
